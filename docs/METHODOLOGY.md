# Методика расчётов

Сервис реализует методику оценки инвестиционных проектов, принятую в российской практике
(«Методические рекомендации по оценке эффективности инвестиционных проектов», ВК 477) и в
решениях Системы Финансовый директор: «Как оценить инвестиционный проект» (универсальная
Excel-модель с листами **CapEx → Financing → Effect → CF → Анализ эффективности**) и каталог
«Финансовые Excel-модели» (разделы *Бюджеты · Отчёты · Инвестиции · Анализ*).

## 1. Структура универсальной модели

| Лист | Что содержит | Как реализовано в сервисе |
|---|---|---|
| **CapEx** | Объекты капитальных вложений: сумма, период, срок полезного использования, метод амортизации | `capex.items[]`, линейная или ускоренная (уменьшаемого остатка, k = 2) амортизация; ликвидационная стоимость — остаточная или заданная |
| **Financing** | Кредиты: сумма, ставка, срок, отсрочка, тип погашения | `financing.loans[]`: аннуитет, дифференцированный, в конце срока; график процентов и тела, остаток долга, DSCR |
| **Effect** | Выручка, переменные и постоянные затраты, экономия, оборотный капитал | ряды по периодам, переменные затраты как % выручки, ОК как % выручки с приростом и высвобождением в конце |
| **CF** | Денежные потоки проекта и собственника, дисконтирование | FCFF, FCFE, коэффициенты дисконтирования, DCF, накопленные потоки |
| **Анализ** | Показатели эффективности и чувствительность | NPV, IRR, MIRR, PI, PP, DPP, ПФ, ДПФ, ARR, DSCR; торнадо, пороги, сценарии, Монте-Карло |

Периоды: `t = 0` — момент старта (инвестиционный период, не дисконтируется), `t = 1…N` —
операционные периоды. Длина периода (год/квартал/месяц) выбирается пользователем; ставка и
ставки кредитов задаются *за период*.

### Денежный поток проекта (FCFF)

```
EBITDA  = Выручка − Переменные затраты − Постоянные затраты + Экономия
EBIT    = EBITDA − Амортизация
NOPAT   = EBIT − Налог на прибыль (без учёта процентов; перенос убытков — опция)
FCFF_t  = NOPAT + Амортизация − CapEx − ΔОК + (Ликвидационная + Терминальная стоимость + Высвобождение ОК)[t = N]
```

### Денежный поток собственника (FCFE)

```
FCFE_t = EBITDA − Проценты − Налог (с учётом процентов) − CapEx − ΔОК + Получение кредитов − Погашение тела + TV[t = N]
DSCR_t = (EBITDA − Налог) / (Проценты + Погашение)
```

### Терминальная стоимость

* модель Гордона: `TV = FCFF_N × (1 + g) / (r − g)`;
* мультипликатор: `TV = EBITDA_N × EV/EBITDA`.

## 2. Показатели эффективности

| Показатель | Формула | Критерий |
|---|---|---|
| NPV | `Σ FCFF_t / (1 + r)^t` | > 0 |
| IRR | `r: NPV(r) = 0` (бисекция, диагностика множественных корней по числу смен знака) | > r |
| MIRR | `(FV притоков по ставке реинвестирования / PV оттоков)^(1/N) − 1` | > r |
| PI | `PV притоков / PV оттоков` | > 1 |
| PP, DPP | период, когда накопленный (дисконтированный) поток ≥ 0, с линейной интерполяцией | ≤ горизонт |
| ПФ, ДПФ | сумма отрицательных (дисконтированных) чистых потоков | — |
| ARR | средняя чистая прибыль / инвестиции | — |

Ставка дисконтирования — как правило WACC: `WACC = E/(D+E) × Re + D/(D+E) × Rd × (1 − T)`,
`Re = Rf + β × MRP + страновая + размер + специфический риск` (CAPM). Реальная ставка — по
формуле Фишера. Шаблон «Расчёт WACC» считает всё это и передаёт результат в поле ставки.

## 3. Анализ рисков

* **«Что если» / таблица чувствительности** — каждый фактор меняется на −30…+30 % при
  неизменных остальных; эластичность = % изменения результата / % изменения фактора.
* **Торнадо** — ±δ по каждому фактору, ранжирование по размаху.
* **Пороговые значения (switching values)** — изменение фактора, при котором NPV = 0
  (корень на отрезке −95…+300 %).
* **Сценарии** — одновременное изменение нескольких факторов с вероятностями → ожидаемое
  значение.
* **Монте-Карло** — треугольное, равномерное или нормальное распределение факторов,
  N итераций (детерминированный ГСЧ), статистики P5/P10/P50/P90, вероятность NPV < 0,
  гистограмма.

### 4.1. EVA: экономическая добавленная стоимость

Источник: Система «Финансовый директор», «EVA: как рассчитать экономическую добавленную стоимость, Excel-модель, образец отчета» (М. Верхотурова) и Excel-модель к ней; методика EVA™ Stern Stewart & Co.

**Формулы.**

* EVA = NOPATскорр − WACC × ICскорр = (ROIC − WACC) × ICскорр, где ROIC = NOPATскорр / ICскорр.
* NOPATскорр = (EBIT + корректировки прибыли) × (1 − T); при отрицательной базе налог не начисляется.
* ICскорр = собственный капитал + процентный заёмный капитал (долгосрочные и краткосрочные кредиты и займы) + корректировки капитала; в расчёт EVA берётся среднее на начало и конец года. Кредиторская задолженность не включается.
* WACC = Wd · Rd · (1 − T) + We · Re по структуре капитала на начало года. Вариант «как в Excel-модели методики»: (Wd · Rd + We · Re) · (1 − T).
* Факторный анализ ΔEVA (цепные подстановки): ΔIC = (ICt − ICt−1)(ROICt − WACCt); ΔROIC = ICt−1(ROICt − ROICt−1); ΔWACC = −ICt−1(WACCt − WACCt−1); сумма равна EVAt − EVAt−1.
* Стоимость бизнеса (формула 3 методики): V = NA0 + Σ EVAt / (1 + d)^t + EVAn (1 + g) / ((d − g)(1 + d)^n).

**Корректировки отчётности** (14 поправок Excel-модели, сгруппированы по механизму):

| Группа | Корректировка прибыли | Корректировка капитала |
|---|---|---|
| 1–4. Маркетинг, реструктуризация, НИОКР, развитие персонала | + расходы периода, − амортизация капитализированных траншей (линейно, по умолчанию 5 лет) | + накопленные расходы − накопленная амортизация |
| 5. Отложенные налоги | + прирост сальдо ОНО − ОНА (только положительный) | + сальдо |
| 6. Гудвилл (РСБУ) | + амортизация за год | + накопленная амортизация |
| 7. Прочие доходы вне EBIT | + сумма | — |
| 8–11. Резервы (LIFO, сомнительные долги, обесценение) | + изменение резервов за год | + накопленные резервы |
| 12. Операционная аренда | + расходы по аренде, − амортизация обязательств (срок аренды) | + приведённая стоимость обязательств |
| 7, 13. Неработающие активы | — | − ликвидные ценные бумаги, незавершённое строительство |
| 14. Чрезвычайные события | — | + накопленные убытки / − прибыли |

**Применение.** EVA не учитывает фактор времени, поэтому в инвестиционном анализе используется вместе с NPV и DCF. В KPI менеджеров включают не саму EVA, а её драйверы: выручку, затраты, объём инвестиций и стоимость капитала.

## 5. Контрольные примеры (покрыты тестами)

* 1 000 000 инвестиций, 250 000 × 5 лет, 10 % → NPV = −52 303 (статья «Расчёт NPV и IRR в Excel»).
* Кредит 1 000 000 на 5 лет под 10 % → аннуитет 263 797; со страховкой 2 % в год реальная ставка ≈ 12,9 %.
* Агрохолдинг (покупка фермы): ПФ = 340, ДПФ ≈ 337, PP = 6-й год, DPP = 9-й год.
* Модель БДР/БДДС сервисной компании: баланс сходится в каждом месяце.
* EVA, компания «Гамма» (статья): NOPAT 20 249 429, IC 40 759 507, WACC 16,83 % → EVA = 13 389 604; динамика за 5 лет совпадает со статьёй с точностью округления WACC.
* EVA, пример Excel-модели методики (2019–2023): NOPAT 88 912 → 62 344, IC 253 150 → 508 900, EVA 57 982 → 3 038 — совпадает с рассчитанными в Excel значениями до рубля (вариант WACC «как в Excel-модели»).
